# CTRL+Z - Catálogo web

Estructura:
- index.html        -> estructura de la página (textos, bloque de pago y ubicación)
- css/styles.css    -> colores y diseño
- js/app.js         -> productos, filtros y botón de WhatsApp (arriba están las 2 líneas de CONFIG)
- img/zeta.png      -> mascota Zeta

Cómo probar: abre la carpeta en VS Code y haz doble clic en index.html.
